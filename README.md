# Microsoft 365 Help Desk & IAM Lab Portfolio

Hands-on Microsoft 365 administration, technical support, and identity and access management (IAM) labs documented as realistic, fictional IT service desk tickets. Each completed project includes the actions performed, verification results, and supporting screenshots.

## Documentation Method

Each lab is structured like a help desk ticket and includes:

1. A fictional user request or support scenario
2. Objectives and prerequisites
3. The actual procedure performed (or a clearly labeled plan)
4. Verification steps and observed results
5. Original, sanitized screenshots when available
6. A final resolution or outcome

## Privacy & Security

All portfolio scenarios and test users are fictional. Labs are performed in a dedicated test environment, not a production customer tenant. Screenshots should be reviewed and redacted before publishing to avoid exposing passwords, authentication codes, access tokens, recovery information, or other sensitive data.
