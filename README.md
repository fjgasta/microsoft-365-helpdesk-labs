## Documentation Approach

Each lab has a scenario, prerequisites, planned procedure, verification checklist, screenshot checklist, and a result section. Once a lab is performed, actual observations and sanitized evidence can be added, and its status updated.

Use the [help desk ticket template](templates/help-desk-ticket-template.md) for future exercises.

## Privacy and Security

All tickets and users are fictional. Do not upload passwords, recovery codes, access tokens, tenant identifiers, real employee information, or screenshots containing sensitive details. Redact screenshots before publishing. Use a dedicated test tenant, not production.
